Built for security. Designed for humans.

Every feature exists to keep your secrets safe without sacrificing usability.

Military-Grade Encryption

Argon2id key derivation + AES-256-GCM encryption. Memory-hard KDF resists GPU/ASIC attacks. Hardware-accelerated on modern CPUs.

Decentralised Sync

Sync via Nostr relays (NIP-44/NIP-59). No central server, no account. Relays see only ciphertext — zero-knowledge by design.

Biometric Unlock

Touch ID, Face ID, Windows Hello, Android fingerprint. OS-native secure enclave protects your vault key — never weakens encryption.

Explicit Device Trust

Every device is explicitly admitted with a secp256k1 keypair. Revocation is immediate. CRDT-based device list handles concurrent changes.

Built-in TOTP

RFC 6238 TOTP generation built right in. No separate authenticator app needed. Secrets stored encrypted alongside your passwords.

Tamper-Evident Audit Log

HMAC-SHA256 hash chain records every vault action. Any tampering is instantly detectable. Full or partial chain verification.

How it works

Simple concept. Bulletproof implementation.

1

Create your vault

Choose a master password. ZVault derives a 256-bit encryption key using Argon2id (64 MiB memory, 3 iterations) — making brute-force attacks computationally infeasible.

2

Add your secrets

Logins, secure notes, cards, identities — all stored in a single encrypted file. AES-256-GCM ensures both confidentiality and integrity. The file header is authenticated, preventing downgrade attacks.

3

Admit devices

Each device generates a secp256k1 keypair. Admit devices explicitly — no implicit trust. The device list uses a CRDT (OR-Set) so concurrent changes merge cleanly.

4

Sync over Nostr

Vault changes are encrypted with NIP-44, signed with NIP-01, and wrapped with NIP-59 (gift-wrap) before being published to relays. Relays see only ciphertext and an ephemeral key — not your identity or your data.

Security by design

Not an afterthought. Every layer is built to minimize trust and maximize verifiability.

◆ Zero-Knowledge Sync

Nostr relays never see plaintext. NIP-59 gift-wrap hides even the sender's real public key. Credentials exist only on your devices.

◆ Memory Safety

Written in Rust. All secret buffers are zeroed on drop via the zeroize crate. Keys never implement Clone or Copy.

◆ Authenticated Headers

The full file header (magic, salt, KDF params, IV) is included in AES-GCM's Additional Authenticated Data. Any header tampering causes immediate rejection.

◆ Forward Upgradability

KDF parameters are stored per-file. Future versions can increase cost params without breaking existing vaults. Re-key upgrades the entire vault atomically.

◆ Fuzz Tested

Vault parser, import parsers, and Nostr handler are continuously fuzz-tested with cargo-fuzz. Property-based tests via proptest.

◆ Auditable & Open

100% open source. Full threat model documented in DESIGN.md. Every security decision is recorded with rationale. No telemetry, no analytics.
